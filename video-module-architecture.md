# Идея: TikTok-подобен модул за кратки видеа

Искаме да изградим модул за кратки вертикални видеа, подобен на TikTok:

- вертикален feed;
- плъзгане нагоре/надолу между видеата;
- автоматично пускане;
- първият кадър да се показва веднага;
- възможно най-бързо стартиране на видеото;
- предварително зареждане на следващото видео;
- автоматично качество според интернет връзката;
- поддръжка на 360p, 480p и 720p;
- харесвания, коментари, споделяния и статистика за гледанията.

## Предложена инфраструктура

Използваме:

- Backblaze B2 за съхранение;
- Cloudflare Free като CDN;
- собствен домейн, например `media.azmigrantat.com`;
- FFmpeg за обработка на видеата;
- PHP API за управление;
- MySQL за metadata, потребители, реакции и статистики;
- мобилното приложение за възпроизвеждане.

Схема:

```text
Мобилно приложение
        ↓
PHP API
        ↓
MySQL + Backblaze B2
        ↓
Cloudflare CDN
        ↓
Мобилното приложение
```

## Качване и обработка

Видеото няма да минава през PHP сървъра. Ще се използва директно качване към B2 чрез временен подписан URL.

След качване:

1. PHP записва видеото със статус `pending`.
2. FFmpeg създава thumbnail.
3. FFmpeg създава версии 360p, 480p и 720p.
4. Създава се HLS playlist (`master.m3u8`).
5. Създават се малки видео сегменти.
6. След успешна обработка статусът става `ready`.
7. Приложението показва само видеа със статус `ready`.

## Бързо стартиране

За бързо възпроизвеждане:

- thumbnail се показва веднага;
- зарежда се първият HLS сегмент;
- следващото видео се предварително зарежда;
- Cloudflare кешира playlist-ите и сегментите;
- видеото се стартира автоматично при показване;
- качеството се избира според интернет връзката.

## Независимост от доставчика

Мобилното приложение няма да използва директни B2 URL адреси.

Ще се използват собствени URL адреси:

```text
https://media.azmigrantat.com/videos/{video-id}/master.m3u8
```

Така по-късно B2 може да бъде заменен с Cloudflare R2 или друга услуга само чрез промяна на backend конфигурацията, без преработка на мобилното приложение.

## Основна цел

Да се изгради евтина и мащабируема система за кратки видеа, която:

- започва без фиксирани месечни разходи;
- използва B2 и Cloudflare Free;
- поддържа много гледания;
- осигурява TikTok-подобно изживяване;
- позволява по-късно мащабиране без основна промяна в архитектурата.
