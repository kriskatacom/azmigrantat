# 🚀 [KRISKATA.COM](https://kriskata.com) — Web Platform

Това е официалният уебсайт на **Кристиан Костадинов** за професионална изработка на уебсайтове. Платформата еволюира от статичен HTML проект в модерно **MVC (Model-View-Controller)** приложение, проектирано за по-голяма сигурност, бързина и лесна скалируемост. Основната цел е да предложи сигурна архитектура, позволяваща добавяне на нови динамични функционалности, управление на клиентски запитвания и административен панел.

Посетете сайта: [KRISKATA.COM](https://kriskata.com)

---

### 🛠️ Технологичен стек

Проектът е изграден с фокус върху чистия код и високите стандарти в уеб разработката:

- **Backend:** PHP 8.x (Персонализирана MVC архитектура)
- **Database ORM:** `Eloquent (Laravel)` — за професионално и сигурно управление на данни.
- **Migrations:** `Phinx` — за версии на базата данни и лесен деплой.
- **Security:**
    - `vlucas/phpdotenv` — за безопасно съхранение на системни променливи.
    - Персонализирана **CSRF** & **Anti-Spam** защита.
- **Frontend:** `Tailwind CSS` — за модерен, адаптивен и олекотен дизайн.
- **Package Manager:** `Composer`.

### ✨ Текущи функционалности

#### 👤 Регистрация на потребители
Регистрацията представлява защитен процес за създаване на потребителски профил с автоматизирано генериране на уникална идентичност, интелигентно разпределение на права (**Admin/User**) и многослойна защита срещу злонамерени ботове и автоматизиран спам.

#### 👤 Потребителски профил
* Лично пространство за управление на информацията.
* Възможност за актуализация на име, потребителско име и биография.
* Динамичен интерфейс с обратна връзка в реално време (Success/Error messages).

### 🚀 Стартиране на проекта

1.  **Инсталиране на зависимости:**
    ```bash
    composer install
    ```
2.  **Настройка на средата:**
    Създайте `.env` файл и конфигурирайте данните за вашата база данни.
3.  **Миграция на базата данни:**
    ```bash
    composer migrate
    ```
4.  **Стартиране на сървъра:**
    ```bash
    composer start
    ```
